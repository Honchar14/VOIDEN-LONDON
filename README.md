# VOIDEN — London

Главный экран и прелоадер сайта стритвир-бренда VOIDEN (версия v16).
Десктоп 1920×1080, чистый HTML/CSS/JS + GSAP (cdnjs) + WebGL.

## Структура
```
index.html            — вся страница (стили, скрипты, шрифты вшиты)
assets/               — фон, логотипы, граффити-теги, иконки
assets/chars/         — кадры персонажей (webp)
assets/chars/vid/     — видео персонажей (mp4 + webm); c4-hero — двойная ширина: кадр + маска
vercel.json           — заголовки кеширования для Vercel
```

## Запуск локально
Нужен любой статический сервер (из `file://` видео и WebGL-текстуры не загрузятся):
```
npx serve .
# или
python3 -m http.server 8000
```

## Тестовые ключи
- `#fast` в адресе — интро ×8, `#slow` — ¼ скорости
- клавиша **R** — повтор интро

## Деплой
Статический сайт без сборки: Vercel → Framework Preset «Other», Build Command пустой, Output Directory `.`.

## Лицензии
Шрифт ABC Monument Grotesk Mono подключён в trial-версии — для продакшена нужна лицензия.
